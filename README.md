# git-project

## Filtered housing page

Open `filtered-options.html` in a browser to view listings from:

- https://www.inberlinwohnen.de/wohnungsfinder/?page=1

The page only shows entries matching:

1. WBS: erforderlich
2. Wohnfläche: under 55 m²

If direct loading is blocked by CORS, the page automatically tries public fallback proxies.
